# Prompt tạo Sổ Bán Hàng

Hãy xây dựng một ứng dụng Android tiếng Việt tên **Sổ Bán Hàng**, ưu tiên đơn giản, nhanh và dễ dùng trên điện thoại.

Yêu cầu:
1. Dashboard hiển thị doanh thu, số đơn, giá trị tồn kho, số sản phẩm và cảnh báo tồn kho thấp.
2. POS bán hàng: chọn sản phẩm, nhập số lượng, tự tính tổng, kiểm tra tồn kho, ghi nhận đơn và trừ tồn.
3. Quản lý sản phẩm: mã, tên, giá bán, tồn kho; thêm mới.
4. Quản lý khách hàng: tên, số điện thoại; thêm mới.
5. Báo cáo doanh thu, số đơn và giá trị đơn trung bình.
6. Dữ liệu hoạt động offline và lưu cục bộ.
7. Giao diện tiếng Việt, rõ ràng, responsive, nút lớn, phù hợp màn hình Android.
8. Không dùng dữ liệu giả làm thay đổi số liệu sau khi người dùng đã thao tác.
9. Dự án phải build được bằng GitHub Actions trên Ubuntu.
10. Mỗi lần cập nhật mã nguồn phải kiểm tra build APK trước khi phát hành.
11. Không phụ thuộc Node.js/npm.
12. README tiếng Việt và workflow build APK hoàn chỉnh.

Mục tiêu triển khai: repository `khahdihdz/tnm`, APK được tạo tự động bởi GitHub Actions.
